## 1. [필수] SeasonalBanner 검은 배너 살리기

### 왜 검게 뜨나

`SeasonalBanner.tsx:8`이 `/images/fw-2026.jpg`를 가리키는데, 정작 그 파일이 들어갈 `public/images/` 폴더가 없습니다. Next에서 `public/` 아래 파일은 루트(`/`) 경로로 서빙됩니다. 그러니 `public/images/fw-2026.jpg`가 있어야 `/images/fw-2026.jpg`로 불러올 수 있는데, 폴더부터 없으니 이미지가 `null`로 떨어지고 그 자리가 비어 보이는 겁니다.

### 방법 A — 실제 이미지를 넣는다 (권장)

폴더를 만들고 시즌 비주얼 이미지를 그 이름으로 넣어주면 됩니다.

```bash
mkdir -p public/images
# 준비한 비주얼을 fw-2026.jpg 이름으로 복사
cp ~/내려받은이미지.jpg public/images/fw-2026.jpg
```

배너는 `fill` + `object-cover`라 가로세로 비율이 어떻든 영역에 맞춰 잘립니다. 다만 화질을 위해 **가로 1600px 이상** 정도를 권합니다(데스크톱에서 풀폭으로 깔리니까요). 넣고 나서 `npm run dev`로 다시 확인하면 검은 영역이 바로 사라집니다.

### 방법 B — 아직 이미지가 없다면 임시 플레이스홀더

확정 이미지가 없으면, 임시로 비어 보이지 않게만 처리해두는 것도 방법입니다. 이미지를 빼고 토큰 색 배경으로 대체해두면 디자인이 깨지지 않습니다.

```tsx
// 이미지 준비 전 임시 버전 — <Image>를 잠시 빼고 배경만
<section className="relative w-full aspect-video md:aspect-4/3 overflow-hidden bg-surface-raised" aria-label="2026 F/W 컬렉션 배너">
  {/* <Image src="/images/fw-2026.jpg" ... /> 준비되면 복구 */}
  <div className="absolute inset-0 bg-surface-overlay" aria-hidden="true" />
  ...
</section>
```

`bg-surface-raised`(zinc-900)가 깔려서 의도된 어두운 톤으로 보입니다. 이미지가 준비되면 `<Image>`만 다시 살리면 됩니다. 어느 쪽이든 콘솔의 `received null` 경고가 사라졌는지 확인해주세요.

> 참고: 만약 이미지가 외부 도메인(CDN 등)에서 온다면 `next.config`에 `images.remotePatterns` 설정이 필요합니다. 지금처럼 로컬 `public/` 안에 두면 그 설정 없이 바로 됩니다.

## 2. [제안] Navbar 노출 위치 정하기

지금 Navbar는 서브페이지 3곳(`/best-pieces`, `/collections`, `/fw-collections`)에서만 `import`해서 쓰고, 홈 `page.tsx`엔 없습니다. 두 가지 선택지가 있습니다.

### 선택지 1 — 홈은 일부러 네비를 뺀다 (현재 상태 유지)

홈은 3D 히어로가 첫 화면을 꽉 채우는 연출이라 네비를 비워두는 것도 디자인 결정입니다. 이 경우 사용자가 홈에서 다른 페이지로 갈 통로(히어로 안의 링크/메뉴)가 분명한지만 확인하면 됩니다.

### 선택지 2 — 모든 페이지 공통으로 둔다

전 페이지에 네비가 필요하면, 각 page마다 `import`해서 반복하는 대신 `layout.tsx`에 한 번만 두는 게 깔끔합니다. 한 곳에서 관리하니 나중에 메뉴를 고칠 때도 한 번만 고치면 됩니다.

```tsx
// src/app/layout.tsx (body 안, children 위)
import Navbar from "@/components/Navbar";
...
<body className="min-h-full flex flex-col">
  <a href="#main-content" className="sr-only ...">본문으로 바로가기</a>
  <Navbar />
  {children}
</body>
```

이렇게 하면 서브페이지 각각의 `<Navbar />`는 지워도 됩니다(중복 제거). 단, 홈에서 네비를 빼고 싶은 의도가 있었다면 선택지 1이 맞습니다. **어느 쪽이 의도였는지부터 정하고** 그에 맞춰 한 곳으로 모으면 됩니다.

## 3. [제안] 제품 카드 이미지는 `next/image`로

제품 사진이 들어오면 ProductCard·CollectionCard도 SeasonalBanner처럼 `next/image`로 가는 걸 권합니다. 패턴은 이미 SeasonalBanner에서 한 번 해보셨으니 똑같이 가면 됩니다.

```tsx
import Image from "next/image";

// 카드 안 이미지 자리
<div className="relative aspect-square overflow-hidden bg-surface-elevated">
  <Image
    src={imageSrc}
    alt={`${name} 제품 이미지`}  // 제품명을 alt에 — 스크린리더·SEO에 좋음
    fill
    sizes="(max-width: 640px) 50vw, (max-width: 1024px) 33vw, 20vw"
    className="object-cover"
  />
</div>
```

`sizes`를 그리드 열 수에 맞춰 적어주면(모바일 2열=50vw, 태블릿 3열=33vw, 데스크톱 5열=20vw) Next가 화면 크기별로 알맞은 해상도만 내려받으니 더 가볍습니다. `alt`엔 제품명을 넣어두면 이미지가 안 떠도 무엇인지 전달되고요.
