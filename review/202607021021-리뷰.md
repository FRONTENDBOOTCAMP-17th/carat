## 1. 지난(16차) 반영 현황 — 유지 확인

16차에서 [제안]으로 남긴 세 가지(컬렉션 3형제 페이지 공통화, 상세 서버 컴포넌트 전환 + per-page 타이틀, 검색 combobox 접근성)는 이미 반영돼 있었고, 이번에 직접 돌려 다시 확인했습니다.

- 상세 페이지 타이틀이 페이지마다 다르게 나옵니다. `/products/collections-0`에 들어가면 `<title>에센셜 원형 밴드 | PRISME</title>`, `<h1>에센셜 원형 밴드`가 뜨는데, `generateMetadata`가 상품별로 잘 붙었네요.
- 검색 모달도 combobox/listbox ARIA로 잘 동작합니다. 인라인 결과 6건, 화살표로 옵션 이동(선택 옵션 읽힘), Enter로 `/products/best-pieces-2` 이동까지 정상입니다.
