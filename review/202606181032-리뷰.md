# carat(PRISME) 8차 코드 리뷰 (2026-06-18)

지난 7차(2026-06-17) 이후 `main`에 들어온 변경을 봤습니다. 정적 랜딩에서 한 걸음 더 나아가 회원가입과 로그인,
위시리스트, 커스텀 커서, 로딩 스크린, 컬렉션 리스트 페이지까지 들어온 회차네요. 디자인 완성도에 무게를 둔 프로젝트라
이번에도 앱을 먼저 띄워 데스크톱·모바일 화면을 직접 봤고(아래 "E2E 결과"), 시각 구현과 반응형, 새로 생긴 화면 위주로 봤습니다.

전체적으로 화면 완성도가 또 한 단계 올라갔습니다. 인증 상태에 따라 위시리스트 접근을 막는 흐름이나 색상 대비·터치 타겟 같은
접근성 보완이 특히 눈에 띄네요. 손볼 것은 지난 회차에 짚은 배너 용량 하나 정도입니다.

## 2. 이번 회차에서 잘된 것

1인 작업으로 한 회차에 화면을 이만큼 늘리면서 완성도까지 지킨 점이 인상적이었습니다.

- **인증 + 위시리스트 가드(`AuthContext`/`AuthGuard`/`LoginModal`)**: 비로그인 상태로 `/wishlist`에 들어가면 LOGIN 모달이 떠서
  접근을 막고, 로그인 상태에서는 "위시리스트가 비어 있습니다 + 컬렉션 둘러보기" 빈 상태 화면이 깔끔하게 나옵니다(E2E D9a·D9b).
  로그인 여부로 화면을 나누는 흐름을 모달·가드·컨텍스트로 잘 쪼개 둔 점이 좋습니다.
- **리스트 페이지(`/best-pieces`·`/collections`·`/fw-collections`)**: 제품 그리드와 가격·설명 레이아웃이 정돈돼 있고,
  데스크톱·모바일 모두 가로 오버플로 없이 깔끔하게 떨어집니다(E2E D7).
- **접근성 보완**: 색상 대비 수정(524c763)과 터치 타겟 보정(035e02c)이 들어왔습니다. 디자이너 출신답게 "보기 좋다"를 넘어
  "쓰기 좋다"까지 챙긴 부분이라 칭찬하고 싶네요.
- **히어로 로딩 동기화(864cfd1)**: 로딩 애니메이션을 실제 에셋 로딩과 연결하고 최소 노출 시간을 둬서 급격한 전환과 깜빡임을 막은 것도
  세심한 처리였습니다.

`npx tsc --noEmit`도 0건으로 깨끗합니다(강사 로컬에서 처음 6건이 떴는데, 최근 추가된 `framer-motion`이 제 `node_modules`에만 없어서였고
`npm install` 후 0건으로 정상이었습니다. 코드 문제가 아닙니다).

## 3. 손봤으면 하는 것 — 배너 이미지 용량 [필수·이월]

`public/images/SeasonalBanner.png`가 34MB입니다. 화면에서는 F/W COLLECTIONS 배너가 잘 보이지만, 한 장에 34MB는
- 첫 화면 로딩을 눈에 띄게 느리게 만들고,
- git에 그대로 올라가 저장소 히스토리를 영구히 무겁게 합니다(한 번 커밋되면 이후에 지워도 히스토리에는 남습니다).

배너 용도라면 보통 수백 KB면 충분합니다. 가로 폭을 실제 표시 크기(예: 1920px 내외)로 줄이고 WebP로 바꾸면 화질은 거의 그대로 두면서
용량을 1/50 수준까지 낮출 수 있습니다. 변환 방법은 가이드에 정리해 뒀습니다. 1인 작업에 수료 일정도 있으니 이번엔 이 한 가지만 가볍게 보면 됩니다.

## 4. 새 화면에 대한 작은 제안

지금 단계에서 꼭 고쳐야 하는 건 아니고, 알아두면 좋은 정도입니다.

- [제안] 인증이 `localStorage`(`prisme_user`/`prisme_wishlist`) 기반의 클라이언트 전용입니다. 디자인을 보여주는 목적에는
  충분하고 적절한 선택이라 생각합니다. 다만 이건 "화면상의 로그인"이지 서버가 검증하는 진짜 인증은 아니라서, 누구든 콘솔에서 값을 넣으면
  로그인 상태가 됩니다. 나중에 실제 백엔드(예: Supabase)를 붙일 생각이 있다면 지금의 `AuthContext` 인터페이스(`login`/`logout`)는
  그대로 두고 내부 구현만 갈아끼우면 되도록 잡아 두면 전환이 수월합니다.
- [사소] 제품 카드 이미지는 아직 회색 플레이스홀더입니다(디자인 단계라 자연스럽습니다). 실제 제품 사진이 들어오면
  `next/image`로 바꾸고 `alt`를 채워 두면 로딩과 접근성이 같이 좋아집니다.
