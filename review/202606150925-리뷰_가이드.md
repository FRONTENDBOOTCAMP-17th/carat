# 해결 가이드 (2026-06-15)

우선순위를 **반응형 하나**에 두고 풀어 썼습니다. 나머지(유령 컴포넌트 정리, `next/image`, 히어로 모바일 대응)는 뒤에 짧게 덧붙였습니다. 혼자 작업하는 만큼 한 번에 하나씩만 가도 충분하다 생각합니다.

---

## 1. 모바일 퍼스트 반응형 붙이기 (최우선)

### 왜 모바일 퍼스트인가

Tailwind의 `md:` 같은 접두사는 "이 크기 **이상**일 때"라는 뜻입니다. 그래서 접두사 없는 기본값을 **모바일**로 두고, `md:`부터 데스크톱 값을 얹는 방식이 자연스럽습니다. 지금 코드는 반대로 데스크톱 값이 기본값으로 박혀 있어서 작은 화면이 무너집니다. 기본을 모바일로 내리고, 큰 화면에만 지금 값을 다시 얹어주면 됩니다.

### 좌우 여백 (`px-24`)

`px-24`는 좌우 96px입니다. 390px 화면에선 콘텐츠 폭이 198px밖에 안 남습니다. 모바일은 좁게, 데스크톱만 넓게.

```tsx
// 변경 전 (BestPieces.tsx:5, Collections.tsx, Footer.tsx 등)
<section className="px-24 py-40">

// 변경 후
<section className="px-6 py-20 md:px-24 md:py-40">
```

`px-6`(24px) 정도면 모바일에서 양옆이 답답하지 않습니다. `py`도 같이 줄여주면 세로가 늘어지지 않습니다.

### 그리드 (`grid-cols-3` / `grid-cols-4`)

핵심입니다. 모바일은 1열, 태블릿 2열, 데스크톱에서 원래 열 수로.

```tsx
// 변경 전 (BestPieces.tsx:14, Collections.tsx:14)
<div className="grid grid-cols-3 gap-12">

// 변경 후
<div className="grid grid-cols-1 gap-8 md:grid-cols-2 lg:grid-cols-3">
```

```tsx
// 변경 전 (Footer.tsx:4)
<div className="grid grid-cols-4 gap-12">

// 변경 후
<div className="grid grid-cols-1 gap-8 md:grid-cols-2 lg:grid-cols-4">
```

이거 한 줄씩만 바꿔도 모바일에서 카드가 위아래로 쌓이면서 글자 겹침이 사라집니다.

### 큰 글자 (`text-6xl` / `text-7xl`)

데스크톱 헤드라인이 모바일에선 화면을 넘칩니다. 모바일은 한두 단계 줄여서.

```tsx
// 변경 전 (Hero.tsx:135)
<h1 className="text-7xl font-light tracking-[0.2em]">PRISME</h1>

// 변경 후
<h1 className="text-4xl font-light tracking-[0.2em] md:text-7xl">PRISME</h1>
```

```tsx
// 변경 전 (BestPieces.tsx:10, Collections.tsx:10 등)
<h2 className="mb-16 text-6xl font-light">

// 변경 후
<h2 className="mb-8 text-3xl font-light md:mb-16 md:text-6xl">
```

### 어떻게 확인하나

브라우저에서 F12 → 기기 툴바(모바일 아이콘)로 폭을 390px로 놓고 봅니다. 한 섹션 고칠 때마다 바로 확인하면서 가면, 한 번에 다 고치고 한꺼번에 점검하는 것보다 훨씬 덜 헷갈립니다. 순서는 눈에 제일 거슬리는 `Footer`(4열)부터 잡는 걸 권합니다.

## 2. `EssentialCollection.tsx` 정리

둘 중 하나만 정하면 됩니다.

**쓸 거라면** `page.tsx`에 붙입니다.

```tsx
import EssentialCollection from "@/components/EssentialCollection";
// ...
<BestPieces />
<EssentialCollection />
<Collections />
```

**안 쓸 거라면** 파일을 지웁니다. 안 쓰는 파일이 남아 있으면 나중에 본인이 "이거 살아 있는 코드였나" 헷갈리고, 빌드 결과물에도 괜히 흔적이 남습니다.

## 3. 제품 이미지가 들어오면 `next/image`

```tsx
import Image from "next/image";

<Image
  src="/products/ring-01.jpg"
  alt="PRISME 솔리테어 다이아몬드 링"  // 무슨 사진인지 한 줄로
  width={800}
  height={800}
  className="h-auto w-full object-cover"
/>
```

`alt`는 빈 칸으로 두지 말고 제품을 설명하는 문장으로 적어주세요. 화면을 못 보는 사용자와 검색 노출 양쪽에 도움이 됩니다.

---

## 4. (선택) 히어로 모바일 대응

3D 히어로는 모바일에서 무겁고, 멀미를 느끼는 사용자도 있습니다. 여유가 생기면 두 가지를 고려해보세요.

- 작은 화면에선 3D 대신 정지 이미지 한 장으로 대체
- `prefers-reduced-motion`을 존중해, 모션을 줄이도록 설정한 사용자에겐 애니메이션을 멈추기

```css
@media (prefers-reduced-motion: reduce) {
  /* 모션 최소화 */
}
```

이건 마감 단계에서 봐도 되는 항목이라 [선택]으로 둡니다.
