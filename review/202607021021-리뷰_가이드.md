## 1. 반응형 마지막 점검 (390px)

크롬 개발자도구에서 디바이스 툴바를 켜고 폭을 390px로 둔 다음 아래를 눌러 보세요.

- `/collections`, `/fw-collections`, `/best-pieces` 목록에서 카드가 가로로 넘치지 않는지 봅니다.
- 긴 제목(h1)이 화면 밖으로 나가지 않는지도 확인하고, 넘친다면 컨테이너에 `break-keep`(한글 단어 유지)이나 `overflow-hidden` + 줄바꿈을 주면 됩니다.

```tsx
<h1 className="text-2xl font-bold break-keep leading-snug">{title}</h1>
```

## 2. 이미지 비율 고정 (레이아웃 이동 줄이기)

`next/image`에서 width/height 중 하나만 CSS로 바꾸면 콘솔에 경고가 뜨고 로딩 중에 화면이 덜컹거립니다(CLS). 비율을 고정해 주세요.

```tsx
// fill 을 쓸 때는 부모에 relative + 고정 비율, sizes 지정
<div className="relative aspect-[3/4]">
  <Image src={src} alt={alt} fill sizes="(max-width: 768px) 100vw, 33vw" className="object-cover" />
</div>
```

## 3. 남은 중복 마크업 정리 (선택)

16차에서 컬렉션 3형제를 공통 컴포넌트로 묶었는데, 혹시 페이지별로 남은 복붙 블록이 있으면 공통 컴포넌트로 마저 넘기는 정도면 충분합니다. 무리해서 구조를 다시 바꾸진 마시고, 눈에 띄는 것만 손보세요.
