## 2. 잘한 점 — 타이포그래피를 제대로 잡았습니다

폰트 셋업이 이번 회차의 백미입니다.

- **Cinzel(헤드라인) + Pretendard(본문)** 조합을 `next/font`로 정석대로 구성했습니다. Cinzel은 `next/font/google`, Pretendard는 로컬 `woff2` 9개 웨이트(Thin~Black)를 `localFont`로 전부 등록하고 `display: "swap"` + CSS 변수(`--font-cinzel`, `--font-pretendard`)로 연결했습니다.
- 브랜드 사이트에서 꽤 중요한 부분입니다. 주얼리 같은 럭셔리 톤은 **세리프 헤드라인 + 정갈한 산세리프 본문**의 대비에서 격이 나오는데, 그 조합을 정확히 골랐습니다. 로컬 폰트라 외부 CDN에 기대지 않고, `swap` 덕에 폰트 로딩 중 깜빡임도 관리됩니다.
- 디자이너 출신답게 "무엇이 고급스러워 보이는가"를 코드로 옮기는 감이 좋습니다.

빌드도 깨끗합니다(`npm run build` 성공, `/`·`/_not-found` 모두 static prerender).

## 3. [필수] 반응형 — 럭셔리 사이트일수록 모바일에서 무너지면 안 됩니다

`src/` 전체에 반응형 브레이크포인트가 하나도 없습니다(`sm:`/`md:`/`lg:` 0개). 모든 섹션이 데스크톱 폭(`px-24`, `grid-cols-3·4`, `text-6/7xl`)으로 고정돼 있어서, 모바일(390px)에서 그리드가 짜부라지고 글자가 겹칩니다. 3차에서도 같은 지적이었습니다.

이게 왜 미룰 수 없는 일이냐면, 브랜드 사이트 트래픽은 절반 이상이 모바일에서 나옵니다. 데스크톱이 아무리 아름다워도 실제 사용자가 폰으로 열었을 때 깨지면 그 브랜드는 "허술하다"는 인상을 주기 쉽습니다. 럭셔리일수록 모바일 완성도가 곧 신뢰라고 봅니다.

지금 데스크톱 완성도가 높으니, 그걸 **모바일 퍼스트로 한 번 뒤집어** 주세요. 기본을 모바일(1열, 작은 패딩·타이포)로 두고 `md:`·`lg:`에서 데스크톱 레이아웃으로 키우는 방식입니다(가이드에 섹션별 예시를 뒀습니다). 디자이너시니 Figma에서 모바일 프레임을 먼저 그린 다음 그 분기를 그대로 코드로 옮기면 빠를 겁니다.

## 4. 브랜드 사이트를 "고급스럽게" 만들 때 신경 쓸 것

동작을 넘어 **격이 느껴지는 웹페이지**를 만들 때 챙기면 좋은 것들을 정리합니다. 박현우님의 시각적 강점에 엔지니어링 디테일을 얹는 방향입니다.

1. **모션은 절제가 곧 고급입니다.** 지금 스크롤 연동 3D 히어로는 멋집니다. 럭셔리 톤에서는 "많이 움직이는 것"보다 "딱 필요한 곳에서 부드럽게"가 비싸 보입니다. 이징은 느리고 묵직하게, 등장은 한 번씩만 하는 식이죠. 여기에 **`prefers-reduced-motion`을 존중**해 주세요. 모션에 민감한 사용자에게 정적 버전을 보여주는 건 오히려 세심함의 표시입니다(접근성도 결국 품질입니다).

2. **무거운 히어로의 로딩 경험도 봐야 합니다.** three.js 3D는 무겁습니다. 첫 화면에서 빈 캔버스나 끊김이 보이면 고급감이 깨지죠. 로딩 중에는 정갈한 포스터 이미지나 블러를 깔아 두고, 준비되면 레이아웃 시프트 없이 부드럽게 전환해 주세요. 모바일에선 3D 대신 고화질 정지 이미지로 대체하는 것도 괜찮은 선택입니다.

3. **이미지는 `next/image`로 가는 게 좋습니다.** 제품 사진이 들어오면 `<img>` 대신 `next/image`를 쓰면 자동 최적화, 반응형 `sizes`, 지연 로딩, CLS 방지까지 따라옵니다. 주얼리는 디테일이 생명이라 화질·로딩이 곧 품질입니다. `alt`도 꼭 챙겨 주세요(접근성과 SEO 둘 다).

4. **타이포 리듬을 토큰으로 묶어 보세요.** 폰트는 잘 잡았으니 다음은 **스케일과 자간**의 일관성입니다. 반복되는 `tracking-[...]`, 색(`text-zinc-600`), 라벨을 디자인 토큰(`@theme`)이나 작은 컴포넌트로 묶으면 페이지 전체의 톤이 한 손에서 나온 것처럼 정돈됩니다.

5. **마이크로 인터랙션도 챙겨 주세요.** 링크·버튼의 hover/focus가 지금 거의 없습니다. 럭셔리 사이트의 "비싼 느낌"은 밑줄이 스르륵 그어지거나 색이 천천히 바뀌는 이런 작은 반응들에서 많이 옵니다. 단, 과하지 않게요.

6. **디테일 정리도 한 번 하면 좋겠습니다.** 유령 컴포넌트(`EssentialCollection`)는 쓰든 지우든 정리해 주세요. 어중간한 파일은 나중에 본인도 헷갈립니다. footer 링크는 텍스트가 아니라 `<a>`로 바꾸고(키보드·스크린리더), 헤딩(h1/h3) 중복도 한 번 정리하면 됩니다.

## 5. 질문 하나 — `lang="en"`

카피가 전부 영어라 `lang="en"`이 의도신가요? 글로벌·에디토리얼 톤을 노린 거라면 `en`이 맞습니다. 한국 사용자 대상이면 `ko`가 스크린리더·검색에 더 맞고요. 의도를 알려주시면 거기 맞춰 더 봐줄게요.
