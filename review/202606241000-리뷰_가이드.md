이번엔 모바일 overflow 하나만 잡으면 됩니다. 나머지는 여유 있을 때 보시라고 가볍게 적어 둡니다.

## 1. 모바일에서 리스트 제목 안 넘치게 (`/collections`, `/fw-collections`)

긴 제목("COLLECTIONS", "FW COLLECTIONS")이 옆의 카운트("12 PIECES")와 같은 줄에서 `justify-between`으로 밀리다 보니 컨테이너를 넘치는 상황인데요, 큰 영어 카피라는 디자인 의도는 살리는 선에서 아래 두 방법 중 하나를 고르면 됩니다.

### 방법 A — 모바일에서 폰트 한 단계 줄이기 (제목·카운트를 같은 줄에 유지)

지금처럼 같은 줄 배치를 유지하고 싶다면, 모바일 폰트만 살짝 줄이면서 제목이 줄어들 여지를 주면 됩니다.

```tsx
<div className="flex items-end justify-between gap-3 mb-8">
  <h1 className="min-w-0 text-4xl sm:text-5xl lg:text-7xl font-light truncate">
    COLLECTIONS
  </h1>
  <span className="shrink-0 ...">12 PIECES</span>
</div>
```

- `min-w-0` — flex 자식이 줄어들 수 있게 풀어 줍니다(기본값이 `min-width: auto`라 안 줄어듭니다).
- `text-4xl`(모바일) → `sm:text-5xl` → `lg:text-7xl` — 작은 화면에서만 한 단계 작게.
- `truncate`는 제목이 정말 길 때 말줄임으로 받쳐 주는 안전장치고, 보통은 폰트 축소만으로 자리에 들어맞습니다.

### 방법 B — 모바일에서 세로로 쌓기 (큰 폰트 유지)

큰 폰트를 그대로 두고 싶다면, 모바일에선 카운트를 제목 아래로 내려 줍니다.

```tsx
<div className="flex flex-col gap-1 sm:flex-row sm:items-end sm:justify-between mb-8">
  <h1 className="text-5xl sm:text-6xl lg:text-7xl font-light">COLLECTIONS</h1>
  <span className="...">12 PIECES</span>
</div>
```

`flex-col`(모바일) → `sm:flex-row`(태블릿 이상)로, 좁을 때만 세로 스택이 됩니다.

### 확인

고친 뒤 390px에서 가로 스크롤이 사라졌는지만 보면 됩니다. 브라우저 콘솔에서 이렇게 확인할 수 있습니다.

```js
document.scrollingElement.scrollWidth <= window.innerWidth  // true 면 OK
```

## 2. 참고 — 여유 있을 때

- **RelatedScroll 스냅**: `scrollBy(±300)` → `scrollBy({ left: 200 })`(카드 폭 176 + gap 24)로 카드 한 칸 단위 이동.
- **상세 이미지**: 실제 이미지 넣을 때 `next/image` `fill` + `sizes` 사용.
- **`CategoryKey`**: `lib/products.ts`의 타입을 import해서 재사용(지역 재선언 제거).

이번 회차도 컴포넌트 접근성과 구조는 탄탄하다고 봤습니다. overflow 하나만 잡고 가면 깔끔해질 거라 생각합니다. 화이팅입니다.
