# 9차 해결 가이드 — 배너 이미지 최적화 + next.config 설정 (2026-06-19)

이번 회차에서 손볼 건 두 가지인데, 사실 한 작업에 묶입니다. 무거운 배너 이미지를 가볍게 바꾸고, 그 김에 `next.config`에
`images.qualities`를 한 줄 넣어 주면 됩니다. 시연(6/22) 전에 10~15분이면 끝나는 작업이라, 첫 로딩 체감을 가장 적은 손으로
끌어올릴 수 있는 부분이라 생각합니다.

---

## 1. 배너 이미지 리사이즈 + WebP 변환 [필수·이월]

### 왜 하는지 먼저

지금 `public/images/SeasonalBanner.png`는 **7952×5304px, 34MB**입니다. 사진 원본 해상도가 그대로 들어가 있는 셈인데,
배너가 화면에서 차지하는 폭은 아무리 커도 1440px 안쪽이라 가로 5배 이상 과합니다. 픽셀이 많을수록 용량이 제곱으로 늘기 때문에
용량이 이렇게 커진 거고요. 가로폭을 표시 크기 수준으로 줄이고 PNG 대신 WebP로 저장하면, 화질은 사람 눈에 거의 차이 없이
용량만 수백 KB(지금의 약 1/50)로 떨어집니다.

### 방법 A — 터미널에서 한 줄 (추천)

`sharp`는 이미 Next가 내부에서 쓰는 이미지 라이브러리라 새로 설치할 필요가 거의 없습니다. 프로젝트 루트에서:

```bash
# 가로 1920px로 줄이고 WebP(품질 80)로 변환
npx sharp-cli -i public/images/SeasonalBanner.png \
  -o public/images/SeasonalBanner.webp \
  resize 1920 --withoutEnlargement \
  toFormat webp --quality 80
```

`sharp-cli`가 없다고 나오면 한 번만 받으면 됩니다(`npm i -D sharp-cli`). 변환 후 용량을 꼭 확인해 보세요.

```bash
ls -lh public/images/SeasonalBanner.webp
```

수백 KB가 나오면 성공입니다. 원본 PNG는 지워도 되지만, 만에 하나를 대비해 백업해 두고 싶으면 `public` 바깥(예: 데스크톱)에
옮겨 두면 됩니다. 저장소에는 가벼운 WebP만 남기는 게 핵심입니다.

> 참고: git 히스토리에는 이미 커밋된 34MB가 남습니다. 지금 단계에서 히스토리까지 청소할 필요는 없고(수료 일정도 있으니),
> **앞으로 무거운 원본을 새로 커밋하지 않는 것**만 신경 쓰면 충분합니다.

### 방법 B — GUI가 편하면

[squoosh.app](https://squoosh.app) 같은 무료 웹 툴에 PNG를 끌어다 놓고, 오른쪽에서 `Resize`로 폭 1920, 포맷 `WebP`,
품질 75~80으로 맞춘 뒤 내려받으면 됩니다. 디자이너시니 미리보기로 화질을 직접 비교하면서 품질 값을 정하는 게 오히려 편할 수 있습니다.

### 코드 한 줄 수정

`src/components/SeasonalBanner.tsx`에서 import 경로만 새 파일로 바꿔 주면 끝입니다. static import라 나머지(`fill`,
`placeholder="blur"`, `priority`)는 그대로 둬도 동작합니다.

```tsx
// 변경 전
import bannerImage from "../../public/images/SeasonalBanner.png";

// 변경 후
import bannerImage from "../../public/images/SeasonalBanner.webp";
```

바꾼 뒤 `npm run dev`로 띄워 배너가 똑같이 잘 뜨는지, 첫 로딩이 빨라졌는지 눈으로 확인해 보면 됩니다.

## 2. `next.config`에 `images.qualities` 추가 [사소·이월]

### 왜 뜨는 경고인지

`SeasonalBanner.tsx`에서 `<Image quality={85}>`를 쓰고 있는데, Next 16부터는 사용할 품질 값을 `next.config`에 미리
선언하도록 바뀌었습니다. 선언이 없으면 기본값 `[75]`만 허용돼서, dev로 띄울 때 이런 경고가 콘솔에 뜹니다.

```
Image with src "/_next/static/media/SeasonalBanner...png" is using quality "85"
which is not configured in images.qualities [75]. Please update your config to [75, 85].
```

기능에는 문제가 없지만, 메시지가 친절하게 "이렇게 넣으라"고 알려주니 그대로 따라 주면 됩니다.

### 수정

`next.config.ts`에 `images.qualities`를 추가합니다.

```ts
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  images: {
    qualities: [75, 85],
  },
};

export default nextConfig;
```

> 한 가지 팁. 이 프로젝트는 Next 16이라 기존에 알던 설정과 조금씩 다를 수 있습니다. 헷갈리면 추측해서 넣기보다
> `node_modules/next/dist/` 안의 해당 문서나 위 경고 링크(`nextjs.org/docs/messages/next-image-unconfigured-qualities`)를
> 한 번 확인하고 가는 게 안전합니다.

저장 후 `npm run dev`를 다시 띄워 콘솔에서 그 경고가 사라졌는지 보면 깔끔하게 마무리됩니다. 배너를 75 품질로 변환했다면
`SeasonalBanner.tsx`의 `quality={85}`를 `quality={75}`로 맞추거나, 위처럼 `qualities`에 두 값을 다 넣어 두면 됩니다.
