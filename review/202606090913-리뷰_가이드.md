## 2. 폰트 일원화 (globals.css)
`font-family: Arial, ...`를 지우고, layout에서 쓰는 Geist 변수로 통일하세요.
```css
body {
  font-family: var(--font-geist-sans), system-ui, sans-serif;
}
```

## 3. 색 토큰화 (Tailwind v4 @theme)
인라인 `bg-[#383838]` 대신 토큰으로:
```css
/* globals.css */
@theme {
  --color-brand: #383838;
}
```
```tsx
className="... hover:bg-brand"
```
디자인 출신이시니, 자주 쓰는 색·간격·라운드 값을 토큰으로 먼저 정의해두면 화면을 빠르게 일관되게 찍어낼 수 있습니다.
