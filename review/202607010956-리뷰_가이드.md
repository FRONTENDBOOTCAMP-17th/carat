## 1. (참고) 상세 페이지가 dynamic(ƒ)이 된 것에 대해

제품 상세를 서버 컴포넌트로 바꾸면서 `cookies()`를 읽다 보니 이 라우트가 요청마다 렌더(ƒ)되는데, **지금은 전혀 문제가 아닙니다.** 다만 나중에 "정적 생성 + 제품별 title"을 둘 다 챙기고 싶어지면 이런 방향도 있다는 것만 기억해 두시면 됩니다.

```tsx
// products/[id]/page.tsx
export function generateStaticParams() {
  // products.json의 모든 id를 미리 굽는다
  return getAllProductIds().map((id) => ({ id }));
}
```

다만 언어를 쿠키로 정하는 지금 구조에선 정적 생성과 쿠키 읽기가 서로 부딪히니 굳이 지금 바꿀 필요는 없고, 언어별로 URL을 나누는(`/ko/...`, `/en/...`) 큰 변경까지 따라와야 해서 마감을 앞둔 지금은 오히려 손대지 않는 편이 맞습니다.

## 2. [사소] `handleSubmit` 타입

```tsx
// 지금
const handleSubmit = (e: { preventDefault(): void }) => { ... };
// 권장 (의도가 또렷)
const handleSubmit = (e: React.FormEvent) => { ... };
```

폼 submit 이벤트라는 걸 타입에서 바로 읽히게 해두면 나중에 코드를 볼 때 의도가 또렷해집니다. 동작은 똑같으니 취향 수준이라 보시면 됩니다.

## 3. [사소·이월] contact / process

15차에서 넘어온 두 가지인데, 급한 건 아니니 여유 될 때만 보시면 됩니다.

- `contact/page.tsx:117`의 "새 문의" `<button>`은 `type`이 없어 기본값이 submit입니다. 폼 안에 들어 있다면 `type="button"`을 명시해 주세요.
