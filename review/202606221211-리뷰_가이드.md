## 1. [제안] 다국어 hydration 경고 줄이기

테마 쪽은 이미 `<html suppressHydrationWarning>`에 anti-flash 스크립트까지 더해 잘 막아 두셨습니다. 지금 남은 경고는 다국어 텍스트가 서버에서는 기본 언어로, 클라이언트에서는 localStorage에 저장된 언어로 그려지면서 둘이 어긋나 나는 것이고요. 아래 두 방향 중 하나만 골라 가시면 됩니다.

**방향 A — 서버에서 초기 언어를 확정해 내려보내기 (권장)**

언어 선택을 `localStorage`에만 두지 말고 쿠키에도 같이 저장해 두면, 서버 컴포넌트나 `layout.tsx`에서 그 쿠키를 읽어 처음부터 맞는 언어로 그려 내려보낼 수 있습니다. 이렇게 하면 서버와 클라이언트가 애초에 같은 텍스트를 그리니 mismatch 자체가 사라지고요.

```ts
// 언어 바꿀 때: localStorage + 쿠키 둘 다
document.cookie = `prisme_lang=${lang}; path=/; max-age=31536000`;

// layout.tsx (서버) 에서 초기 언어 결정
import { cookies } from "next/headers";
const lang = (await cookies()).get("prisme_lang")?.value ?? "ko";
// 이 lang 을 LanguageProvider 초기값으로 내려보냄 + <html lang={lang}>
```

**방향 B — 언어 의존 텍스트는 마운트 후 렌더 (간단)**

`LanguageContext`에 `mounted` 상태를 하나 두고 마운트 전에는 기본 언어로만 그리는 방법입니다. 경고는 사라지지만 첫 프레임이 잠깐 기본 언어로 보일 수 있어서, 깔끔하게 가려면 역시 A 쪽이 낫다고 봅니다.

```tsx
const [mounted, setMounted] = useState(false);
useEffect(() => setMounted(true), []);
// 텍스트 렌더 시 mounted 이전엔 기본 언어 키 사용
```

기능에는 지장이 없으니 급하면 시연 끝나고 봐도 됩니다.

## 2. [사소·이월] `next.config` 이미지 quality 설정

배너가 `<Image quality={...}>`를 쓰고 있는데 `next.config`에 `images.qualities`가 빠져 있어서 콘솔에 경고가 뜨고 있습니다. 아래처럼 한 줄만 채워 주면 됩니다.

```ts
// next.config.ts
const nextConfig = {
  images: {
    qualities: [75, 85],
  },
};
```
