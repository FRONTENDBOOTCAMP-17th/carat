# carat 4차 리뷰 — 해결 가이드 (2026-06-11)

## 1. [필수] 반응형 — 모바일 퍼스트로 뒤집기

핵심 발상: **기본값 = 모바일**, `md:`·`lg:`에서 데스크톱으로 키우기. 지금은 데스크톱 값이 기본이라 모바일이 깨집니다.

### 패딩
```tsx
// before (데스크톱 고정)
<section className="px-24 py-32">

// after (모바일 기본 → 점점 키움)
<section className="px-6 py-16 md:px-12 md:py-24 lg:px-24 lg:py-32">
```

### 그리드 (BestPieces / Collections)
```tsx
// before
<div className="grid grid-cols-4 gap-8">

// after (모바일 1열 → 태블릿 2열 → 데스크톱 4열)
<div className="grid grid-cols-1 gap-6 sm:grid-cols-2 lg:grid-cols-4 sm:gap-8">
```

### 타이포 (히어로 헤드라인 등)
```tsx
// before
<h1 className="text-7xl">

// after
<h1 className="text-4xl md:text-6xl lg:text-7xl">
```

### Footer (4열 → 모바일 1~2열)
```tsx
<div className="grid grid-cols-2 gap-8 md:grid-cols-4">
```

> 팁: Figma에서 모바일(390) 프레임을 먼저 만들고, 그 수치를 기본값으로, 데스크톱 프레임 수치를 `lg:`에 넣으면 그대로 옮겨집니다. 크롬 개발자도구의 디바이스 툴바(390px)로 확인하며 작업하세요.

## 2. 3D 히어로 모바일 대체 + reduced-motion

```tsx
"use client";
import { useEffect, useState } from "react";

function useReducedMotion() {
  const [reduced, setReduced] = useState(false);
  useEffect(() => {
    const mq = window.matchMedia("(prefers-reduced-motion: reduce)");
    setReduced(mq.matches);
    const on = () => setReduced(mq.matches);
    mq.addEventListener("change", on);
    return () => mq.removeEventListener("change", on);
  }, []);
  return reduced;
}

export default function Hero() {
  const reduced = useReducedMotion();
  // 모바일/모션최소 사용자에겐 정지 이미지, 그 외엔 3D
  if (reduced) return <HeroStatic />;   // 고화질 포스터 이미지 버전
  return <Hero3D />;
}
```
모바일 판단은 화면 폭(`window.matchMedia("(max-width: 768px)")`)으로도 같이 분기하면, 무거운 three.js를 폰에서 안 돌려 배터리·발열·로딩이 좋아집니다.

로딩 중 포스터(레이아웃 시프트 없이):
```tsx
<div className="relative aspect-[16/9]">
  {/* 항상 깔리는 정지 이미지 */}
  <Image src="/hero-poster.jpg" alt="" fill priority className="object-cover" />
  {/* 준비되면 위에 부드럽게 페이드인되는 3D 캔버스 */}
  <Canvas className={`absolute inset-0 transition-opacity duration-700 ${ready ? "opacity-100" : "opacity-0"}`} ... />
</div>
```

## 3. 제품 이미지가 들어오면 next/image

```tsx
import Image from "next/image";

<Image
  src="/pieces/ring-01.jpg"
  alt="PRISME 솔리테어 다이아몬드 링"   // 비어 있지 않게
  width={800}
  height={1000}
  sizes="(max-width: 768px) 100vw, 33vw"  // 반응형 폭 힌트
  className="object-cover"
/>
```
주얼리는 화질이 곧 품질입니다. `sizes`를 주면 모바일에선 작은 이미지를 받아 빠르고, 데스크톱에선 선명합니다.

## 4. 타이포·색 토큰화 (선택)

`globals.css`의 `@theme`에 반복 값을 모으면 톤이 정돈됩니다.
```css
@theme {
  --tracking-luxury: 0.2em;
  --color-ink: #18181b;     /* zinc-900 계열 본문 */
  --color-muted: #52525b;   /* zinc-600 라벨 */
}
```
```tsx
<span className="tracking-[var(--tracking-luxury)] text-[var(--color-muted)]">ESSENTIAL</span>
```

## 5. [정리] 유령 컴포넌트 / hover / 헤딩
- `EssentialCollection.tsx`: 쓸 거면 `page.tsx`에 import, 안 쓸 거면 삭제.
- 링크에 hover/focus: `className="transition-colors hover:text-ink focus-visible:underline"` 정도만 더해도 "비싼 느낌"이 납니다.
- 헤딩: 페이지에 `h1`은 하나만(보통 히어로 브랜드명). 나머지는 `h2`/`h3`로.
