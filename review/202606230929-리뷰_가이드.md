## (선택) 위시리스트를 여러 기기에서 공유하고 싶다면

지금은 localStorage에 담고 있어서 기기나 브라우저가 바뀌면 위시리스트가 따로 놉니다. 당장 손댈 일은 아니고, 나중에 기기 간 동기화가 필요해지면 Supabase 테이블 하나만 두면 됩니다.

```sql
create table wishlist (
  user_id uuid not null,
  product_id text not null,
  created_at timestamptz default now(),
  primary key (user_id, product_id)
);
-- 본인 것만 읽고 쓰게 RLS
alter table wishlist enable row level security;
create policy "own wishlist" on wishlist
  for all using (auth.uid() = user_id) with check (auth.uid() = user_id);
```

```ts
// 토글: 있으면 삭제, 없으면 추가
await supabase.from("wishlist").upsert({ user_id, product_id });   // 추가
await supabase.from("wishlist").delete().eq("user_id", user_id).eq("product_id", product_id); // 제거
```

이때 로그인도 실제 Supabase Auth로 바꿔야 `auth.uid()`가 제대로 동작합니다. 지금처럼 localStorage 로그인을 그대로 둘 거라면 위시리스트도 localStorage가 맞는데요, 한쪽만 백엔드로 옮기면 인증과 데이터가 서로 어긋나기 쉬우니, 옮길 거면 인증과 같이 옮기는 게 좋습니다.

## (선택) 모바일 히어로 카피 가독성

모바일에서 카피가 3D 링과 겹쳐 잘 안 읽히면, 카피 영역에만 살짝 배경을 깔거나 위치를 조금 조정해주면 됩니다.

```tsx
{/* 모바일에서만 카피 뒤에 옅은 배경 */}
<div className="md:bg-transparent bg-white/60 rounded-md px-3 py-2">
  <p>The essence of ...</p>
</div>
```

링을 가리지 않으면서 글자만 또렷해지는 정도면 충분합니다. 의도한 디자인이라면 그대로 두셔도 됩니다.
